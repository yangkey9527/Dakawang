# 打卡王 (DakaWang)

一款 Android 平台的**自定义每日打卡提醒**应用：把每天要做的签到打卡任务（抖音极速版、快手极速版、番茄小说、蚂蚁森林……）集中管理，到点提醒，每晚复查，避免错过打卡错过收益。

## 功能特性

- **自定义打卡任务**：任意添加需要每日打卡/签到的应用或事项，可指定目标应用包名
- **模板库一键添加**：内置常见打卡应用的模板（签到关键词、打卡入口提示已配好），一键添加即可用
- **应用图标自动提取**：指定目标应用后，任务卡片自动显示该应用的真实图标
- **到点提醒，通知直达**：每个任务可独立设置提醒时间，点击通知直达目标应用
- **每晚 22:30 复查提醒**：汇总当天仍未完成的任务再次提醒——很多打卡过了 12 点就没机会补打了
- **自动确认打卡（只读无障碍检测）**：在目标应用内检测到"已签到"等关键词时，自动标记任务完成（可选开启，仅读取界面文字，不做任何自动操作）
- **平台区分**：任务可分"手机 APP / PC 客户端 / 网页"三类，PC 类任务（如 WorkBuddy）带平台徽标，点击「去打卡」仅提示、不会误跳转
- **今日进度**：首页直观显示今日完成进度

## 内置模板

红果短剧、拼多多、多邻国、蚂蚁森林、抖音极速版、今日头条极速版、番茄免费小说、快手极速版、吉利汽车、WorkBuddy（PC）

## 工作原理与系统限制

受 Android 系统安全限制，本应用**不包含任何自动点击、模拟操作能力**，打卡操作仍需用户手动完成。它做的是三件事：

1. **提醒**：到点发通知，点击通知直达目标应用
2. **直达**：通过应用包名拉起目标应用（跳过手动寻找入口）
3. **检测**：可选开启无障碍服务，只读识别界面上的"已签到"等文字，帮你在打卡后自动标记完成

## 环境要求

- Android 8.0+（API 26+）
- 需要**通知权限**用于每日提醒
- 自动确认打卡功能需要**无障碍服务权限**（可选，按需开启）

## 构建

使用 [Android Studio](https://developer.android.com/studio)（推荐最新稳定版）打开项目根目录，等待 Gradle 同步完成后点击 Run；或使用命令行：

```bash
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

## 技术栈

- Kotlin
- Jetpack Compose + Material 3
- Room（本地数据库）
- DataStore（设置存储）
- WorkManager（后台提醒调度）
- AccessibilityService（只读打卡检测）

## 权限说明

| 权限 | 用途 |
|---|---|
| `QUERY_ALL_PACKAGES` | 列出已安装应用，用于模板库选择目标应用 |
| `POST_NOTIFICATIONS` | 发送每日提醒通知 |
| `BIND_ACCESSIBILITY_SERVICE` | 自动确认打卡（只读检测，可关闭） |
